# Excel VBA エクスポーター

Windows上のExcelブックからVBAソースを取り出す、Python製のデスクトップツールです。
ファイル選択またはドラッグ＆ドロップで対象ブックを指定し、選択したフォルダーへ
標準モジュール、クラスモジュール、フォームをエクスポートできます。

## 動作環境

- Windows 10 / 11
- Python 3.12
- Microsoft Excel デスクトップ版
- `uv`（セットアップに使用）

Excelブックは読み取り専用で開きます。ブック／ワークシートのコードモジュールは
エクスポートしません。

## セットアップ

リポジトリのルートで、依存関係をインストールします。

```powershell
uv sync
```

`uv sync` はプロジェクト用の仮想環境を作成し、必要なパッケージをインストールします。
`pywin32` と `tkinterdnd2` はこのプロジェクトの依存関係として管理されます。

## Excel側の設定

VBAプロジェクトを読み取るため、Excelで次の設定を有効にしてください。

1. Excelの **ファイル** > **オプション** を開きます。
2. **トラスト センター** > **トラスト センターの設定** を開きます。
3. **マクロの設定** で **VBA プロジェクト オブジェクト モデルへのアクセスを信頼する** を有効にします。
4. 作業中のブックを保存し、Excelをすべて終了してから再実行します。

この設定を有効にできない場合、または組織のポリシーで禁止されている場合は、
管理者に確認してください。マクロの実行を許可する設定とは別の設定です。
「プログラミングによるVisual Basicプロジェクトへのアクセスは信頼性に欠けます」
などのエラーが出る場合も、この設定を確認してください。
ツールはこのセキュリティ設定を自動変更しません。マクロをすべて有効にする必要はありません。

## 起動方法

```powershell
uv run python -m excel_vba_exporter
```

## 使い方

1. GUI全体（入力欄・ボタン・ラベル・余白）へExcelファイルを1つドロップするか、
   **対象Excelファイル** の **参照...** から選びます。どこへドロップしても対象欄に反映します。
2. **出力先フォルダー** の **参照...** を選びます。
3. **エクスポート** を押します。
4. 完了またはエラーのメッセージを確認します。

対応するファイル形式は `.xls`、`.xlsm`、`.xlsb`、`.xlam` です。出力先に同名の
ファイルが既にある場合は、既存ファイルを上書きせず処理を中止します。

## 出力されるファイル

| VBAコンポーネント | 出力形式 |
| --- | --- |
| 標準モジュール | `.bas` |
| クラスモジュール | `.cls` |
| フォーム | `.frm`（フォームによっては`.frx`もExcelが作成） |

`ThisWorkbook` とワークシートのコードモジュールなど、ブックにひも付くコードは
対象外です。

## 制限事項

- Excelデスクトップ版がインストールされているWindows環境が必要です。
- VBAプロジェクトへのアクセス許可が必要です。アクセスできない場合は、Excelの
  トラストセンター設定を確認してください。
- パスワードで保護されたVBAプロジェクトはエクスポートできません。利用権限のある
  プロジェクトはExcelのVBAエディターで保護を解除して保存し、ブックを閉じてから再実行してください。
- Excelがブックを開けない場合、破損している場合、または組織のポリシーでVBAへの
  アクセスが禁止されている場合は処理できません。
- ブックは読み取り専用で開き、変更を保存しません。
- エクスポートされたファイルにはVBAソースコードが含まれます。保存先と共有先を
  適切に管理してください。

## 開発・テスト

開発用の依存関係も含めて環境を同期します。

```powershell
uv sync --group dev
```

テストと静的解析を実行します。

```powershell
uv run pytest
uv run ruff check .
```
